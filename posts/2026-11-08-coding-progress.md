## Focus of the Day

Re-establishing practical software development skills and understanding the modern web development ecosystem.

## What I Explored

### 1. Backend Development: Node.js and Express.js
- Reviewed Node.js as a JavaScript runtime powered by Google's V8 engine.
- Explored Express.js as a backend framework.
- Practised routing, HTTP requests and responses.
- Examined how Express serves pages and processes form submissions.

### 2. Frontend Fundamentals: HTML, CSS and JavaScript
- HTML provides page structure and elements such as forms, checkboxes and buttons.
- CSS controls visual presentation, including layout, spacing, typography and colours.
- JavaScript adds behaviour and interactivity.
- React and Vue help structure and manage interactive frontend applications.
- Understood that frontend frameworks do not automatically determine visual beauty; CSS and design choices remain essential.

### 3. Web Development Architecture
- Reviewed PHP, Python and JavaScript in web development.
- Distinguished runtimes, frameworks, libraries, databases and deployment platforms.
- Explored the evolution of web development and significant industry milestones.
- Compared traditional and modern full-stack architectures.

### 4. Git and GitHub
- Explored repository consolidation and project organization.
- Practised Git Bash and command-line workflows.
- Reviewed GitHub Pages as a static website hosting platform.
- Explored how GitHub repositories control website content and deployment.
- Started developing a weekly coding progress documentation approach.

### 5. Software Engineering: Taskflow 2.0
- Reviewed the transition from traditional PHP architecture to Next.js.
- Explored TypeScript, Tailwind CSS and PostgreSQL.
- Distinguished Node.js as a runtime from Next.js as a framework.
- Considered modern development workflows using GitHub and Vercel.

## Key Takeaways

- Node.js is a runtime; Express.js is a backend framework.
- HTML defines structure; CSS defines presentation; JavaScript adds behaviour.
- React and Vue organize interactive frontend applications.
- Web applications consist of multiple interconnected architectural layers.
- GitHub is both a development platform and a learning documentation tool.

## Next Steps

- Build a React frontend connected to an Express API.
- Practise form handling and data submission.
- Explore database integration.
- Continue consolidating GitHub repositories.
- Document weekly development progress.

## Reflection

Today was about rebuilding my mental model of modern web development: understanding what each technology does, how the components connect, and how to design complete software systems.

The objective is not simply to learn programming syntax, but to develop the ability to design, build, secure and govern software systems.
